Browser agents are language model assistants that navigate websites, fill forms and click buttons on behalf of a user. Because they see page contents and often hold the user credentials, they create new privacy risks. An agent may leak personal data to third party sites, or send sensitive information to a remote model provider. Proposed defenses include running the model locally, redacting personal identifiers before pages are sent to the model, and restricting which domains the agent can act on. Another approach is to separate the planning model from a local executor that holds secrets, so the planner only ever sees placeholders. Researchers also evaluate whether agents follow malicious instructions hidden in web pages, which is a form of prompt injection. Privacy preserving designs aim to give the agent the minimum information needed to complete each step.
