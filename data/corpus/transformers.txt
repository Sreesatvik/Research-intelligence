The transformer architecture processes a sequence of tokens in parallel using self attention. For every token, the model computes a query, a key and a value vector. The similarity between a token query and every other token key determines how much attention it pays to each, and the output is the weighted sum of the value vectors. This lets a word like it directly look at the noun it refers to, however far away that noun is. Multiple attention heads run in parallel so the model can track different relationships at once, such as syntax and coreference. Because attention has no built in notion of order, positional information is added to the token embeddings. Stacked transformer blocks, each combining attention with a feed forward network and residual connections, build increasingly abstract representations. Encoder models like BERT are good at understanding, while decoder models generate text one token at a time.
